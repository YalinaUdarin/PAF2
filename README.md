## About

This repository covers Git branching, Pull Requests, and the GitHub Flow workflow, completed as part of the IT3030 module at SLIIT.

---

## Topics Covered

- Creating and switching branches (`git branch`, `git checkout -b`)
- Pushing feature branches to remote
- Creating and merging Pull Requests (PRs) on GitHub
- Collaborating with a colleague via shared repositories
- Practising the GitHub Flow branching strategy

---

## Key Commands Practised

```bash
git clone <url>
git checkout -b feature/<name>/<feature>
git push origin <branch-name>
# then create PR on GitHub and merge to main
```

---

## GitHub Flow

`main` → create feature branch → commit changes → open PR → review → merge → delete branch
